Quick Start:
------------
1. Configure:   cp .env.docker .env && nano .env
2. Build:       docker-compose build
3. Run CLI:     docker-compose --profile cli run --rm baileys-cli
4. Run Web UI:  docker-compose --profile web up -d
5. Access:      http://localhost
